# Програмний проєкт 5, варіант 5
Харченко Поліна К-28

Обчислення: A1, A2, B1, B2, C, D, F.
Повільні (7 с): A1, B2. Решта швидкі (1 с).
Залежності: A2(A1), B2(B1), F(C), D(A2, B2).

## Схема виконання

- Головний потік: B1, B2, потім чекає потік 1, далі D, потім чекає потік 2.
- Потік 1 (`async`): A1, A2.
- Потік 2 (`async`): C, F.

Час виконання 9с (A1 + A2 = 8, B1 + B2 = 8, потім D = 1).
Запускається 2 додаткових потоки, одночасно працюють 3. Менше не можна: сумарна робота 19 с, а двох потоків за 9 с вистачає лише на 18 с.

Для запуску потоків використано тільки `<future>` (`async`, `future::get`). Вивід синхронізовано через `osyncstream`.

## Файли

- `program.cpp`: функція `main`, викликає `work`.
- `work.h`, `work.cpp`: функція `work`, що виконує обчислення за схемою і виводить час та `Work is done!`.
- `computations.h`, `computations.cpp`: функції `slow` (7 с) і `quick` (1 с).
- `CMakeLists.txt`: збірка.
- `results.txt`: вихід програми.
- `diagram.png`: діаграма розподілу обчислень по потоках і точок синхронізації.

## Збирання і запуск

```
cmake -S . -B build
cmake --build build
build\project5.exe
```

Вивід у файл:

```
build\project5.exe > results.txt
```
